# Course Example — “从信息孤岛到个人工作台”

## Classification

- Two-episode course; 1920×1080, 30 fps
- EP01 builds the workspace; EP02 uses it in daily work
- One efficient recording day: Pocket block, real-vault read-only block, demo-vault SOP block, workflow block

## EP01 stage allocation

| Chapter | Stage | Primary proof |
|---|---|---|
| Hook / result | Screen Focus, then Presenter | HOME → Project → Meeting → Link path |
| Obsidian basics | Concept Motion | local workbench / vault / link / authorized Codex |
| Word vs Obsidian | Concept Motion → real screen | isolated files vs connected work information |
| SOP00 | Screen Focus | same local directory and read-only verification |
| SOP01 | Motion + 1–2 evidence screens | role / work / projects / meetings / material / pain points regroup into workspace |
| SOP02 | Screen Focus + state motion | Before → Build → After with real resulting workspace |
| Ending | Presenter Stage + summary slate | next episode promise |

## Pre-render gates

1. Visual beat plan proves that voice and current screen state match.
2. Screen direction plan contains Full Context → Focus → Highlight → Hold for every real operation.
3. Annotation manifest validates and the review sheet is visually approved.
4. Motion hero frames show Start → Change → End and readable result holds.
5. Contact sheet contains no repeated PPT-like pages or stale evidence.
6. Export and flash-frame checks pass from originals/source projects.
