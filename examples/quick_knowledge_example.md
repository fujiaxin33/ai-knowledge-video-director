# Quick Knowledge Example — “AI 不好用，可能是问题没说清”

## Classification

- 55 seconds, 1080×1920, 30 fps
- Evidence-led talking head with one real AI screen demonstration
- Primary carrier: Presenter for hook/turn/ending; real screen for proof; light overlay for the comparison

## Beat sketch

| Time | Spoken job | Visual carrier | Meaningful event |
|---:|---|---|---|
| 0–4s | Ask the problem | Presenter Stage | Hook title reveals beside face |
| 4–12s | Show vague input | Screen Focus | Full ChatGPT context → prompt focus → response hold |
| 12–20s | Explain missing context | Concept Motion | four compact context cards assemble |
| 20–35s | Show improved input/result | Screen Focus | full context → focus → two intentional highlights |
| 35–45s | Compare | Concept Motion | vague/specific results align side by side |
| 45–55s | Summarize | Presenter Stage | one-line rule + ending hold |

## Director decisions

- Do not leave a full prompt page on screen while the narration has moved to the result.
- Do not cover-crop information screens; establish the complete page first.
- The comparison uses short labels, not duplicate subtitles.
- Any alternate talking-head sentence is fully covered by screen or motion.
