# Production Regression Example

For a 90-second software teaching video, do not start with motion assets. First lock speech and proof:

```text
Transcript + Audio
→ Clean A-roll EDL/QC
→ Canonical Terms
→ Screen Hygiene
→ Visual Beats / Evidence
→ Motion / Annotation
→ Final QC
```

Example decisions:

- A repeated/failed Talking Head start is removed by semantic audio review, not silence detection.
- A software screen with taskbar keeps app/page/result context while removing unrelated OS UI.
- A long Prompt appears briefly as proof, then becomes a compact summary.
- A supplied AI motherboard is decomposed; simple cards/lines are rebuilt, not pasted full-screen.
- A central result panel receives a measured annotation only after a complete context frame.
- A verified product logo appears once with canonical name and short role; text-only is used if provenance is uncertain.
- A rolling 10-second concept-only window is marked `PPT_RISK` and reviewed semantically.

This example describes planning and gates. It does not claim that final aesthetic approval can be automated.
