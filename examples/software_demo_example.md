# Software Demo Example — “连接 Codex 与 Obsidian Vault”

## Classification

- 3–4 minute horizontal tutorial, 1920×1080, 30 fps
- Real software is the main visual; presenter appears large only in hook/transition/ending and otherwise 14–18% fixed PIP or hidden

## Pre-production locks

- Lock Clean A-roll before timing the screen sequence.
- Build project-specific canonical terms for `Codex` and `Obsidian` from the approved script and verified UI/assets; validate final subtitles and labels.
- If verified logos are available, use each once at its first identity moment with a short role; do not keep them floating through the demo.

## Screen direction excerpt

| Beat | Full Context | Focus | Highlight | Hold |
|---|---|---|---|---|
| Vault identity | Obsidian app + vault name + file tree | vault name/path region | exact selected vault and local path | 1.2s |
| Same directory | Codex window and workspace header | opened folder/path | exact matching directory string | 1.5s |
| Read-only check | full Codex conversation | user instruction card | “只检查，不修改” and confirmed path | 1.5s |

## Annotation contract

- Freeze the selected source frame before measuring.
- Record target rectangle in final 1920×1080 pixels.
- Box padding is 8–20 px and balanced within 4 px.
- Underlines span the exact phrase and follow its text baseline.
- The review sheet shows both the full frame and close-up before rendering.

## Avoid

- A box around the entire right half when the spoken target is one prompt card.
- Cropping away the Obsidian file tree when the teaching point is the vault structure.
- A highlight line positioned from memory rather than measured pixels.
- Leaving taskbar, unrelated tabs/projects, notifications, private UI, or inherited burned captions in the teaching screen.
- Using an AI-generated app screenshot or logo as proof when the real UI/asset exists.
