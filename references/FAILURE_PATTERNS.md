# Failure Patterns

| Failure | Why it fails | Default correction |
| --- | --- | --- |
| Person remains large through teaching | Content becomes secondary | Fixed 14%–18% PIP or hide Presenter |
| Large face + tiny content | Software cannot be read | Screen Stage / Screen Focus |
| Software page hangs too long | Static evidence becomes waiting | Freeze Explain, summary, motion, or continue |
| Long Prompt scroll wait | Viewer cannot read it at pace | 0.8–1.2s evidence then summarize |
| Crop loses context | Viewer cannot locate action | Full context then semantic focus |
| Multi-level zoom | Disorientation and softness | One restrained focus or Freeze Annotation |
| Annotation misses target | Visual instruction becomes false | Recompute final-canvas target rectangle |
| Box includes large unrelated UI | Attention remains ambiguous | Tight 8–20px padding |
| Line count differs from spoken points | Motion and narration disagree | One mark per taught point |
| Target moves but box does not | Annotation becomes visibly wrong | Freeze, recompute, or track |
| Card only appears | Motion is decoration | Add change and result lock |
| Long blank intermediate state | Video feels unfinished | Build fast, hold complete result |
| Consecutive PPT pages | Template fatigue | Real evidence or state-based motion after two |
| Motion repeats speech | Competing information | Compress to concept copy |
| Karaoke/bounce subtitle | Captions steal attention | Stable semantic phrase subtitle |
| SFX covers voice | Teaching becomes tiring | Lower, reduce, align only key impacts |
| Voice enhance sounds synthetic | Trust and natural tone fall | Conservative chain + Raw/Processed test |
| Preview used as source | Quality and timing degrade each revision | Rebuild from originals/source projects |
| Low-bitrate screen export | Fine UI text breaks after upload | Higher-quality source export and native-size check |
| One-frame leak/flash | Underlayer or blank is exposed | Integer-frame coverage and boundary review |
| Direct visible take switch | Background/light jump | One Master Take; cover necessary switch |
| Ending introduces a new unrelated layout | Narrative feels abruptly reset | Continue the established result/summary stage |

Do not add a failure to this library from one project-specific preference. Promote only repeated or clearly transferable failures after user confirmation.
