# Internet-Native Storytelling Layer

Use this optional layer when cultural recognition, reaction timing, self-deprecation, or an unexpected event materially improves the explanation. It composes with `STANDARD` or `WHITEBOARD_STORYTELLING`; it never replaces the primary evidence mode.

## Route in only when justified

Route IN when the audience and platform support informal cultural language and the concept can be taught through a recognizable event. Route OUT for formal enterprise work, requested no-humor delivery, regulated evidence, or when a meme would distract from real software proof.

Internet-native does not mean more stickers. Each punch must record:

`Setup -> Action -> Impact -> Reaction -> Knowledge purpose -> Exit`

If nothing happens and the frame only adds labels, arrows, boxes, or reaction images, the punch fails.

For a 60–150 second video, 2–6 effective punches is a planning suggestion, never a quota. Knowledge remains primary; do not force one joke every ten seconds.

## Internet language pass

When the script has not yet been recorded, allow internet language to grow into the spoken performance through contextual personification, self-deprecation, life situations, contrast, or short verdicts. Avoid a fixed catchphrase library. A 60–150 second script may contain roughly 2–5 obvious language punches when natural; already-locked speech is never rewritten by this layer without authorization.

## Cultural meme reference layer and real meme policy

- A cultural reference supplies meme DNA, composition, timing, or recognition; do not copy a face, logo, film frame, dialogue, or distinctive protected composition into the final asset.
- Default to a whiteboard/comic interpretation built from original or authorized assets.
- `REAL_MEME_INSERT` is OFF by default. Enable only with explicit authorization, documented source/license, a maximum intentional flash duration, and a planned transition back into the project visual world.
- A real insert that weakens visual coherence must be removable without changing the explanation.

## High-quality assets and “Image Becomes”

The storyboard image describes the final state, not the entry method. Preserve the approved final asset quality. Choose one:

- `MASK_DRAW`: Hand/reveal front exposes the high-quality asset progressively.
- `ASSEMBLY_BUILD`: outline -> subject -> expression -> prop -> text -> detail.
- `HAND_REVEAL`: mask follows the Hand tip.
- `TRANSFORM`: an existing object becomes the next scene object.
- `COMEDY_POP`: only when sudden appearance is itself the impact.

Do not simplify a finished asset into a debug icon or stick-figure placeholder merely to claim it was hand drawn.

## Color and reaction rhythm

Knowledge defaults to restrained project colors. Comedy may build from line art into a controlled color burst, then erase, desaturate, wipe, or transform back to the teaching canvas. Preserve the reaction pause. Never speed up the punch or reaction simply to hit duration.

## Internet annotation

Use at most one short annotation per beat. It should appear briefly, add attitude, then exit. It is not a new label system and must not compete with the main action.

## Required artifact

An `INTERNET_PUNCH_MAP` records Punch, Setup, Action, Impact, Reaction, Knowledge Purpose, Color State, Asset Source, Entry Method, Exit, and real-meme status.
