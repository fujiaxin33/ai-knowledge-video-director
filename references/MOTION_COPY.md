# Motion Copy

Motion copy is a compressed teaching label, not a second subtitle.

## Length

- Chinese concept: usually 2–8 characters.
- English concept: usually 2–6 words.
- One card carries one idea; supporting copy stays subordinate.

## Transformation

Convert explanation into a relationship or state:

```text
“信息没有讲清楚，结果当然只能很普通”
→ 输入模糊
→ 输出泛化
```

Prefer:

- action → result;
- before → after;
- input → process → output;
- evidence → conclusion;
- status labels that change.

Avoid:

- copying the full spoken sentence;
- repeating the subtitle verbatim;
- vague labels such as “重点” with no semantic target;
- paragraphs inside motion cards;
- more copy than can be read during the final hold.

Use monospace for parameters, paths, numbers, or tool states; use the project text face for explanatory copy.
