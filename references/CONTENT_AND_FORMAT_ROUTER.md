# Content and Format Router

## Classify before designing

Choose the lowest level that can teach the outcome without hiding necessary evidence.

| Level | Typical request | Duration | Default evidence | Default motion |
| --- | --- | --- | --- | --- |
| 1 — Quick Knowledge | One Prompt tip, concept, or method | 30–75s | Human + brief real Screen | HyperFrames light motion; Remotion optional only if state change is essential |
| 2 — Tool / Skill Demo | GitHub Skill, AI tool, Before/After, software operation | 60–120s | Screen first + small Presenter PIP + real result | HyperFrames; Remotion for multi-state explanation |
| 3 — Course / Flagship | Multi-chapter workflow, Obsidian + Codex, project case | 2min+ | Chaptered Screen / Motion / Presenter | HyperFrames + Remotion by beat; chapter-level QC |

Do not inflate a Level 1 video to demonstrate the production system. A Level 3 course may still route individual beats to `NO EFFECT`.

## Canvas router

### 9:16

Use for person-led viewpoints, mobile-native quick knowledge, short sharing, and narrow UI evidence that remains readable. Horizontal information screens must be contained or reframed semantically; never crop them merely to fill the canvas.

### 16:9

Use for software teaching, long Prompt/output, tables, GitHub, Obsidian, Codex, courses, and complex motion. Readability outranks platform habit.

## Preset selection

1. If a project `DESIGN.md` exists, its brand tokens win.
2. Use `Editorial Brand` when the brand is warm, restrained, and explanatory.
3. Use `Presenter Motion UI` only when the reference intent is information-stage rhythm and presenter/content integration.
4. Use `Dark Motion UI` only when explicitly requested or clearly supported by the brand.
5. A reference contributes layout, density, state progression, Presenter relation, subtitle rhythm, and SFX rhythm—not copied logos, copy, colors, or signature components.

## Required classification output

Record: level, canvas, audience, learning outcome, target duration, primary evidence, selected preset, and one-sentence rationale.
