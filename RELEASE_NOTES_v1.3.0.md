# v1.3.0 — Internet-Native Live Drawing Production Pipeline

v1.3.0 promotes repeated production failures into explicit gates while preserving v1.2.0 behavior.

## Highlights

- `STANDARD` and `WHITEBOARD_STORYTELLING` remain the primary modes.
- `INTERNET_NATIVE_STORYTELLING` and `LIVE_DRAWING_STORYTELLING` are optional, composable layers.
- Draw While Talking, Hand-as-actor, continuous canvas, knowledge residue, and anticipatory empty space formalize live drawing.
- Internet punches are events with setup, action, impact, reaction, knowledge purpose, and exit—not sticker collections.
- Real meme inserts default OFF; cultural references usually guide original whiteboard/comic interpretation.
- Speech now has clause-level semantic retake, approved coverage, local-speed ripple, and final start-to-end listening gates.
- Voice/visual facts, object lifecycle, scale, captions, callbacks, SFX, entry methods, render budget, and human approval are validated before release.

## Validation

The executable suite contains 16 test groups, including an exact 20-case matrix for production regressions 1–12 and Live Drawing regressions A–H. Validators assess structured declarations and produce review evidence; they do not replace human listening, rights review, comedy judgment, or aesthetic approval.

## Compatibility

Projects that do not route the new layers continue to use the existing Standard or v1.2 Whiteboard workflow. Historical v1.2.0 files and release history remain unchanged.
