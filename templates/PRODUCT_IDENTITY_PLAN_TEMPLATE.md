# Product Identity Plan

| Product / platform | Canonical name | Verified asset | Provenance | First identity moment | Short role | Later reuse | Safe-zone notes | Status |
|---|---|---|---|---|---|---|---|---|
|  |  | path / URL / none | official / user supplied / project asset | time / beat | 2–6 words | none / evidence / router | face / subtitle / annotation / software text | approved / gap |

## Rules

- Use `Logo + Canonical Name + Short Role` only when recognition helps the current teaching point.
- Prefer first introduction, tool routing, or real result/evidence.
- Do not persistently float logos or turn the video into advertising.
- Never fabricate or AI-imitate a real product logo.
- If provenance cannot be verified, use canonical text only and record an asset gap.
