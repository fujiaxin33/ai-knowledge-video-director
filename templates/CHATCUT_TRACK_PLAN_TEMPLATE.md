# ChatCut Track Plan

| Track | Role | Allowed media | Audio policy | Notes |
|---|---|---|---|---|
| V5 | Annotation / UI emphasis | boxes, underlines, markers, labels | none | Bind to final-canvas geometry |
| V4 | Motion overlays | HyperFrames / Remotion alpha or branded panels | none | Never conceal required evidence |
| V3 | Presenter PIP | approved Pocket takes | source muted unless intentional | Fixed 14–18% width during teaching |
| V2 | Screen / B-roll | OBS, real software, prepared evidence | normally muted | Full Context → Focus → Highlight → Hold |
| V1 | A-roll continuity | master talking-head take | master voice | No one-frame leaks beneath coverage |
| S1 | Subtitles | one stable Simplified Chinese caption system | none | One line preferred; no karaoke |
| A2 | Music / ambience | optional licensed bed | ducked | No masking of consonants |
| A1 | Dialogue master | master take + approved inserts | target around -16 LUFS, peak ≤ -1 dBTP | A/B any material processing |

## Boundary Audit

- [ ] Every overlay starts/ends on integer frames.
- [ ] Adjacent covers share a boundary or overlap by one frame when required.
- [ ] No information screen reveals A-roll for ≤2 frames.
- [ ] Ending holds the semantic result until the spoken sentence finishes.
